# 开发路线图

AI CRM 系统的发展规划和版本迭代记录。

## ✅ v3.0 - 当前版本

**发布日期**：2026-10

**核心主题**：AI 驱动的智能邮件 CRM

### 已完成功能

#### 邮件管理
- [x] IMAP 邮件拉取
- [x] 多邮箱支持（QQ、163、Gmail、Outlook 等）
- [x] 邮件自动去重（基于 Message-ID）
- [x] 邮件列表展示与分页
- [x] 邮件详情查看
- [x] 已读/未读标记
- [x] 已回复标记
- [x] 邮件优先级（高/中/低）
- [x] 手动修改邮件优先级

#### AI 邮件分析
- [x] 邮件意图识别
- [x] 智能优先级判断
- [x] 邮件摘要生成
- [x] 回复草稿生成
- [x] 中英双语支持
- [x] 批量分析

#### 客户管理
- [x] 客户自动建档
- [x] 客户列表与搜索
- [x] 客户详情页
- [x] 客户优先级（hot/warm/cold）
- [x] 客户等级（A/B/C）
- [x] 客户画像（AI 生成）
- [x] 客户邮件往来历史

#### AI 智能助手
- [x] 全局 AI 助手面板
- [x] Agent 模式（可执行系统操作）
- [x] 多轮对话与上下文记忆
- [x] 动作类型：修改优先级/等级、搜索客户、生成跟进等
- [x] 邮件专属 AI 助手
- [x] 邮件自动分析（打开邮件时自动触发）
- [x] 快捷操作（润色、翻译、摘要、生成跟进等）
- [x] 会话管理与历史记录
- [x] AI 记忆功能

#### 跟进计划
- [x] 自动生成跟进计划
- [x] 自定义跟进规则
- [x] 跟进完成标记
- [x] 逾期跟进提醒
- [x] 今日待办统计

#### WhatsApp 集成
- [x] 聊天记录导入（粘贴/文件上传）
- [x] 多种格式支持
- [x] 自动解析消息
- [x] AI 对话分析（情感、意图、摘要）
- [x] 客户自动关联

#### 系统功能
- [x] 多账号支持与切换
- [x] 授权码加密存储
- [x] 数据清空
- [x] 响应式 UI 设计
- [x] 一键启动脚本（Windows + Linux/macOS）
